# 🍎 Heavenly Apple

A simple static fruit shop website deployed on AWS S3 using Terraform.

## 🚀 Technologies

- HTML
- CSS
- JavaScript
- AWS S3
- Terraform

## 🏗️ Architecture

User
↓
AWS S3 Static Website
↓
HTML / CSS / JavaScript

Terraform is used to provision the AWS infrastructure.

## ✨ Features

- Heavenly Apple landing page
- Fruit varieties section
- Services section
- Benefits section
- Responsive design
- Hosted on AWS S3

## 📁 Project Structure

heavenly-apple/ ├── website/ ├── terraform/ ├── README.md └── .gitignore

## ⚙️ Deployment

Initialize Terraform:

terraform init

Review the infrastructure:

terraform plan

Deploy:

terraform apply

## 🧹 Destroy Infrastructure

terraform destroy
